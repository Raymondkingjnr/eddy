# Lesson Mentor

Lesson Mentor is intended to help a user create and manage educational lessons and projects. Users should be able to create content manually or request AI-assisted lesson/project generation, edit lesson content, delete lessons,
and manage only their own resources.

## Repository Structure

This repository is organized as a monorepo:

```text
frontend/                 Vue 3 frontend application
backend/                  FastAPI workspace
docs/backend-fastapi/     API contract documentation
docs/frontend/            Frontend documentation
```

## Frontend Stack

- Vue 3
- TypeScript
- Vue Router
- Tailwind CSS
- Vitest and Vue Test Utils
- ESLint and Prettier

## Backend Stack

- FastAPI
- SQLAlchemy
- Pydentic
- Python 3
- SQLite for local development (without Docker), Postgres in Docker and production

## Running with Docker (recommended)

The quickest way to run the whole app. You need Docker with Compose v2 (Docker Desktop) and nothing else: no local Python, Composer, Node or Postgress.

Start everything from `docker/`:

```bash
cd docker
docker compose build --no-cache backend frontend
docker compose up -d
```

Open http://localhost:5173 and sign in with the seeded user:

```text
Email:    amara.okafor@example.com
Password: password
```

to open the swagger doc: http://localhost:8001/docs

```bash
# Start / stop
docker compose up -d              # start in background
docker compose stop               # stop, keep containers
docker compose down               # stop and remove containers (data is kept)
docker compose down -v            # also deletes the database volume (full reset)

# Rebuild only after changing Dockerfiles or dependencies
docker compose up -d --build
docker compose up -d --build --renew-anon-volumes   # after changing package.json

# Migrations
docker compose exec backend alembic revision --autogenerate -m "comment"
docker compose exec backend alembic upgrade head
docker compose exec backend alembic downgrade -1
docker compose exec backend alembic current

# Seeding
docker compose exec backend python seed.py

# Debugging
docker compose logs -f backend
docker compose exec db psql -U postgres -d lesson_mentor
```

### Migrations

```text
The backend runs alembic upgrade head on every start. After a plain docker compose up, existing migrations are already applied, so you only need the commands above for new ones.
Because backend/ is bind-mounted, a revision you generate lands in backend/alembic/versions/ on your Mac. Review it, then run upgrade head, or restart the backend.
Check autogenerated migrations that touch the embedding columns. They may need an import pgvector line at the top to run.
```

### Seeding

```text
seed.py only needs to run once per fresh database, because the data persists. After down -v you’ll need to seed again.
Run  seed.py
```

## Getting Started (without Docker)

Install dependencies:

```bash
pnpm install
pnpm dev
```

### Backend with SQLite

Local development uses SQLite. `backend/.env` points at `sqlite+aiosqlite:///./lesson_mentor.db`, so the database file is `backend/lesson_mentor.db`. Docker sets its own Postgres `DATABASE_URL`, which overrides `.env`.

```bash
cd backend
uv sync
uv run alembic upgrade head   # create the schema
uv run python seed.py         # seed once per fresh database
uv run fastapi dev main.py
```

To reset, delete `backend/lesson_mentor.db` and run the migration and seed again. Embedding columns are stored as plain text on SQLite, so vector similarity search needs Postgres with pgvector.
